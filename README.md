# Digital Humanity Midterm

This is a multi-page website exploring various aspects of digital art and how technology influences the creation and consumption of art. This site was made for my Digital Humanity class at the University of Pittsburgh. The website is built using HTML, CSS, and JavaScript.

## Pages

1. **Home** (`index.html`): The landing page with a brief introduction and navigation links.
2. **Interactivity** (`interactivity.html`): Discusses the role of interactivity in digital art forms like video games, museum displays, social media, and chatbots.
3. **Mediums** (`mediums.html`): Explores different software tools and mediums used for digital art creation, such as Photoshop, Illustrator, and Procreate.
4. **Democratization** (`democratization.html`): Examines how the internet has democratized information and enabled the sharing of digital content, both legally and illegally (e.g., Napster).
5. **Preservation** (`preservation.html`): Discusses the challenges and implications of preserving digital art and memories in the age of abundant data storage.

## Features

- **Responsive Design**: The website is designed to be responsive and accessible on various devices and screen sizes.
- **Navigation Menu**: A hamburger menu is implemented for easy navigation on smaller screens.
- **External Links**: External links are provided for further reading and resources.
- **Dynamically Updated Footer**: The footer displays the current year using JavaScript.
- **Social Media Links**: Links to the author's social media profiles are included in the footer.

## Usage

To view the website locally, simply open the site in a web browser. The website is self-contained and does not require any additional setup.

## Dependencies

The website relies on the following external resources:

- **Google Fonts**: The website uses the `Roboto` font family from Google Fonts.
- **Font Awesome**: The website uses Font Awesome icons for social media links.
